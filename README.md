本地 3D 资产的布置与几何间距排练：导入受支持的 glTF/GLB，选中、拖动或用数值摆放，解释包围代理的重叠/间隙/房间越界/自定留白带，保存两种方案并导出可审阅报告。

## 实际可用功能

- 完整原创程序场景，内含长凳、单椅、介绍台、陈列台、枝叶装置。自带需要改进的重叠和留白带示例。
- 真正复用本地 vendored Three.js 0.180.0 与 OrbitControls（MIT）：透视/俯视、缩放/旋转、点击选中、移动模式拖放并以 0.1m 吸附。WebGL2 不可用时明确降级为可操作俯视图；数值布置与几何检查仍可运行。
- 名称、X/Z、旋转、等比缩放、0.1m 方向微调、复制/移除、撤回/重做。画布聚焦后方向键微调，Shift+方向键每次0.5m。
- 本地 glTF 2.0 JSON / GLB 导入；无上传、无远程URI解析。为文件计算 SHA-256，记录人工单位覆盖、源文件名、顶点/三角形数与来源声明。
- 定向包围矩形的分离轴重叠判断、边界最近距离、房间边界检查、自定中央留白带；每条提醒都有对象、方法及数值。
- A/B 快照与并排比较。检查参数不相同时明确提示不可把提醒数量减少直接解释成改善。
- 方案JSON、Markdown报告、完整JSON报告；包含位置变换、资产来源声明与指纹、每对物件间距、方法限制、A/B方案参数与几何数据。
- 自动本机保存方案和快照。导入网格留在当前标签页内，刷新后用明确标记的包围代理恢复；重新导入相同文件和单位恢复网格。保存失败时当页继续工作，提示导出JSON。

## 启动

需要 Node.js 22 或更新版本；不需要安装依赖，Three.js 已随仓库提供。

```sh
npm test
npm run check
npm run build
npm run dev
```

开发服务默认 `http://127.0.0.1:4187`，可用 `PORT` 覆盖；有 `dist/` 时优先服务构建产物，修改源码后重新 build。浏览器通过本地 HTTP 或 HTTPS 打开，ES modules 不支持直接 `file://` 运行。文件指纹使用 Web Crypto，需要 HTTPS 或 localhost。

静态输出 `dist/` 包含本地 Three.js、原始 MIT 许可、自有模块和原创导入样例；运行时没有 CDN、网络API或模型服务。用“下载原创测试资产”取得 `fixtures/original-sample.gltf` 后，可以完整验证导入、布置和报告，不需要第三方素材。

## 支持的导入子集

- glTF **2.0** JSON：内嵌 `data:application/octet-stream;base64,...` 或 `data:application/gltf-buffer;base64,...` 缓冲；GLB **2.0**：JSON + 单个内嵌 BIN。
- 静态、未压缩 `TRIANGLES`；`POSITION` 为 FLOAT32 VEC3；可选 unsigned 8/16/32位索引；支持合法 byteOffset/byteStride、节点层级、TRS或仿射matrix。
- 按默认场景展开节点变换后，水平居中并落地；不保留源场景绝对位置。glTF默认米，厘米/毫米是人工确认后的覆盖选项。
- 显示 `baseColorFactor`，重算法线。忽略贴图、其他材质属性与动画并在导入记录中注明；**不会请求图片或其他外部URL**。这不是材质保真查看器。
- 暂不支持外部 `.bin`、Draco、Meshopt、量化坐标、蒙皮、形变目标、sparse访问器及其他必需扩展。遇到不支持的几何明确拒绝，而不是假装导入成功。
- 限制：12 MiB输入文件、20 MiB解码缓冲、200,000展开顶点、400,000三角形、80图元、400节点；最多60资产、40摆放物件。极薄方向以1mm代理并提示。

## 检查的准确边界

每个物件用“局部包围盒的宽×深，经旋转后的定向矩形”表示，属于**保守几何代理**。正值是矩形边界最短水平距离；零是接触；负值是代理重叠的最小分离位移。凳脚之间、枝叶空隙和凹形模型可能被保守地标记；不等于真实网格相交。

只处理水平地面摆放，不做精确网格碰撞、物理仿真、人体可通过性、承重、施工、消防、无障碍或其他法规判断。默认0.6m间隙与1m留白带只是可编辑示例，**不是法规推荐值**。单位、比例、资产授权及Aholo来源声明必须由使用者人工核对；自述Aholo导出不会被标为已核验。
