# 留白实验室项目报告源稿

更新于2026-11-10。此源稿用于制作5页非商业赛事报告。已核验真实Lux3D生成、下载、导入、同参数A/B浏览器操作及实际报告下载。PDF生成脚本读取实际下载数据与真实截图裁切；原始GLB不随报告公开，生成内容明确标注AI来源。材料准备与官方作品交件分开记录。

## 第1页 生成模型之后 如何解释这版布置

留白实验室面向需要摆放生成模型的个人创作者：把支持的glTF/GLB放入本地小型展陈场景，调整位置、旋转与尺度，解释每条保守包围代理提醒，并留下可复核的两版方案。

实际流程是“生成并保留来源 -> 核对文件和单位 -> 布置 -> 按同一参数比较A/B -> 导出报告”。本地工具不上传模型，不连接远程模型或CDN；Three.js与OrbitControls随仓库提供。

## 第4页 用相同参数比较实际A与B

实际保存A后，将导入物件从X=0、Z=0移到X=-2、Z=1.8，同时应用两项数值，再保存B。旋转0度、缩放1保持不变。比较数据直接读取本次浏览器下载报告，提醒4→2；没有把预期结果写入导出文件。

## 第5页 方法边界 复现与素材披露

每件物件使用局部包围盒宽深经旋转得到的定向矩形。负间隙是代理最小分离位移，零是接触，正数是代理边界最近距离；凹形、细腿和枝叶空隙可能被保守标记。

本工具不判断承重、消防、无障碍或人体可通过性。0.6m间隙和1m留白带是可改示例，不是法规推荐。导入只支持明确的静态、未压缩、内嵌缓冲glTF/GLB子集，不支持外部BIN、Draco/Meshopt、蒙皮等；贴图、动画和其他材质效果不作保真承诺。

原创代码和程序样例采用MIT；实际复用Three.js0.180.0与OrbitControls并保留原始许可。Lux3D生成资产受平台条款约束，不自动继承代码MIT。当前只作非商业、带AI标识的赛事展示；商业和二次分发授权未核实，原始模型保持私密。

Codex协助设计、实现、测试及文案。核心导出物件实际由Lux3D生成，其他五件示例为原创程序几何；本地布置工具运行时不调用LLM。报告中的界面素材来自真实操作截图的裁切，任何视频剪辑也须明确不是连续录屏。
