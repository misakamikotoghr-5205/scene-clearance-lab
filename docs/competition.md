# Aholo 全球 3D AI 黑客松：官方规则与本项目状态

核对日期：2026-11-04 UTC。主要依据是 [中国官方公开活动页](https://www.aholo3d.cn/hackathon)，交叉核对 [英文官方活动页](https://www.aholo.ai/hackathon)。登录后的“我的参赛”页面没有公开可读字段，因此未假装读取报名授权条款、提交表单或账户状态。

## 当前可参加性

- 公开规则：全球开放、线上参加，面向开发者、设计师、创作者、学生及研究者，没有在公开FAQ中排除中国大陆个人开发者。
- 队伍1–3人；单人也须创建团队，每个账号同时只能属于一支团队。具体账号实名、年龄、税务或奖金发放条件以报名时实际条款为准，本次未登录核实。
- 报名2026-10-19开始；**作品提交与成员锁定均在2026-11-19 19:00北京时间（UTC+8）**。等于2026-11-19 11:00 UTC；英文页写当日06:00 EST（UTC−5），时区换算一致。
- 评审11-20至11-30，12月初公布结果。以核对日计，提交截止尚未到来。

## 作品与平台硬条件

官方明确要求 **Aholo Lux3D 参与核心3D内容或关键创作流程**。Aholo API、LuxReal及其他第三方工具可选，不是必须调用API。本项目没有发明或声称存在私有接口，也没有填入平台密钥。

活动不设固定命题。必交区列出可直接体验或运行的Demo链接，以及包含真实运行画面的Demo视频；区块标题写“链接或视频”。为避免公开文字与后台字段差异，交付计划准备可运行链接和真实操作视频两者，最终按实际提交表单确认。源代码链接/压缩包、带 `#Aholo黑客松` 的小红书公开介绍列为加分材料；本项目没有自动发帖或代投。

公开评分：群核技术栈应用30%、有趣程度25%、创新性20%、完成度20%、传播5%；专家70%与玩家30%加权。素材、代码、模型、音乐及数据都必须有合法授权；展示、传播和获奖作品使用范围以最终规则及报名授权条款为准。

## 这个项目现在达到了什么

已完成：原创程序展厅、实际Three.js复用、可操作本地导入子集、3D布置、可解释几何代理检查、方案对比和可审阅报告。内置资产和下载样例均由本项目原创，不使用未授权3D素材。

**尚未完成且不能由本地Demo替代：**

1. 用户在官方平台注册/建队并接受当期实际条款。
2. 在 Aholo Lux3D 中真正生成核心布置资产，保留相应运行、授权与生成记录。
3. 合法导出静态glTF/GLB，核实是否能得到本工具支持的未压缩、内嵌缓冲子集；若平台实际输出不支持，则调整兼容实现或人工导出流程并复测，不能先声称已兼容。
4. 用真实导出资产进行核心布置排练，记录导出选项、单位、源文件SHA-256、成功导入画面与问题解释，制作真实运行视频。
5. 按活动后台字段正式提交作品。托管预览、GitHub推送、手选“Aholo来源”均不等于已满足技术栈要求或已报名/提交。

因此，本作品目前应描述为 **“可独立体验、为Aholo生成资产下游工作流准备的原型；真实Lux3D使用与导出兼容性待账号验证”**，不能描述为已完成所有参赛条件的正式作品。
